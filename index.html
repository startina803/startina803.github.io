LINE 機器人｜垃圾不落地

2025/8 ~ 2025/8

開發整合臺北市政府開放資料 API 的 LINE 聊天機器人，使用者可透過分享定位，即時查詢附近街道垃圾桶位置，並以 LINE Flex Message 呈現最近垃圾桶資訊及 Google Maps 導航連結。

射擊遊戲：消除惱人的蚊子

2025/7 ~ 2025/7

以純 HTML/CSS/JavaScript 開發的瀏覽器射擊遊戲，玩家以電蚊拍游標在限時內擊中螢幕上隨機出現的蚊子以獲得分數，具倒數計時、音效與最高分紀錄功能，可直接於瀏覽器執行。

開發內容
